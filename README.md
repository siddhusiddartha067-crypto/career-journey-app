# 🚀 Career Journey – Engineering Student Career Companion

A personalized career development companion designed to help engineering students plan, track, and improve their software development journey.

## 🎯 Purpose

Career Journey helps students organize their learning roadmap, practice Data Structures & Algorithms, manage daily learning tasks, track projects, and prepare for software engineering careers.

## ✨ Features

- 👋 Personalized student dashboard
- 🗺️ 12-step Software Developer roadmap
- 📚 Daily learning and tasks
- 🔥 Learning streak tracking
- 💻 Data Structures & Algorithms practice
- 📊 Progress tracking
- 🚀 Project management
- 🎯 Career and interview preparation
- 👤 Student profile
- 📱 Mobile-friendly interface
- 💾 Progress and task data saving
